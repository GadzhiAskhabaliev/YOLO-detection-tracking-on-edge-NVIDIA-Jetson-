# Tracking pipeline implementation prompt

Ты работаешь в репозитории:
`/Users/criptyn97/real time detection and tracking on edge`

Задача: реализовать ПОЛНЫЙ воспроизводимый пайплайн трекинга людей:
YOLOv8n-CrowdHuman + ByteTrack, включая:
1) настройку окружения,
2) загрузку MOT17,
3) запуск трекинга,
4) экспорт результатов в MOTChallenge формат,
5) оценку трекинга через TrackEval (MOTA/IDF1/HOTA),
6) замер speed (FPS/latency),
7) обновление docs и артефактов.

Сделай это end-to-end, без остановки на “плане”.

Ограничения:
- Не ломай текущий benchmark-пайплайн детекции.
- Новые скрипты клади в `scripts/tracking/`.
- Все пути и команды должны быть воспроизводимы на Vast.ai инстансе.
- Если чего-то не хватает (например, kaggle creds), зафиксируй это как блокер и предложи fallback.
- Не делай git commit/push, только подготовь изменения и отчет.

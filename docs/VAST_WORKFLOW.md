# Как совмещать репозиторий и инстанс Vast.ai

Идея: **в git только код и заметки**; **тяжёлые данные и веса** живут на диске инстанса (`/workspace`) и не попадают в коммиты.

## Роли

| Где | Что хранить |
|-----|-------------|
| **Локально / GitHub** (`этот репо`) | `scripts/`, `configs/` YAML под эксперименты, `docs/`, малые утилиты |
| **На Vast** (`/workspace/...`) | `data/` (CrowdHuman, MOT17), скачанные `.pt`, кеш `kagglehub`, результаты прогонов |

Пути на машине могут отличаться: в скриптах лучше одна переменная окружения, например `export PROJECT_ROOT=/workspace/real-time-edge`.

## Цикл работы

1. На ноутбуке правишь скрипты в репо → коммит → пуш на GitHub (или без GitHub: только локально).

2. На инстансе **один раз** клонируешь репозиторий:
   ```bash
   cd /workspace
   git clone https://github.com/YOU/YOUR_REPO.git real-time-edge
   cd real-time-edge
   ```

3. Дальше перед каждой сессией на Vast:
   ```bash
   cd /workspace/real-time-edge && git pull
   ```

4. Датасеты не тянуть через git — качать как у тебя в инструкции в `/workspace/data`, а в YAML указывать абсолютный путь `path:` под это дерево.

5. Результаты бенчмарков можно сохранять в **`results/` локально на инстансе** и только маленькие JSON/plots забрать через `scp` или дописать в заметки — они уже в `.gitignore`.

## От блоков «копируй в терминал» к файлам в репо

Пока удобно гонять **куски команд из чата**. Когда блок стабилен:

1. Сохрани его как файл в репо, например `scripts/vast/install_deps.sh`, `scripts/vast/download_crowdhuman.sh`.
2. Добавь в начале `set -euo pipefail` и короткий комментарий «что делает».
3. На Vast: `bash scripts/vast/install_deps.sh`

Так и история эксперимента в git, и повторяемость без простыней в терминале.

## Замечания по твоей инструкции (важно)

- **`pip install`** на образах NVIDIA часто надёжнее через `python3 -m pip install ...`, чтобы не поставить пакеты не тому интерпретатору.

- **Конвертация CrowdHuman в YOLO**: фиксированные `1920×1080` для всех картинок дают **неверные нормализованные координаты**. Для честного mAP нужно читать реальный размер каждого изображения (например `cv2.imread` → `shape`) и считать `xc, yc, nw, nh` от него.

- **Замер FPS через `model(dummy)`**: у Ultralytics корень модели не всегда эквивалентен «полному» пайплайну инференса. Для сравнения моделей либо явно вызывай внутренний forward (`model.model(tensor)`), либо `predict()` на массиве — и одну из двух стратегий зафиксируй для всего исследования.
